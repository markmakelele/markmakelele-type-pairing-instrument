# Type Pairing Instrument

An open-source typographic laboratory for exploring typeface pairing, hierarchy, rhythm, context, and reading direction.

## What it does

- H1–H7 hierarchy controls
- Display / Text typeface pairing
- Font search and classification
- Serif / Sans / Mono / Display filters
- Pairing modes
- Kerning / tracking
- Leading
- Linked and independent kerning/leading controls
- Context break
- Hyphenation
- Left / centre / right / justified alignment
- LTR / RTL testing
- Insight-word highlighting
- Roman / italic controls
- Variable-weight controls where supported
- Editable heading and paragraph specimen
- Pairing heuristic score
- Hover descriptions for controls
- Light / dark theme
- Local font file library
- Direct font links
- Browser-side font caching for added fonts
- Drag-and-drop font loading
- Added-source management

## Run

Open `index.html` in a modern browser.

For local font files and browser cache behaviour, serving the project from a local HTTP origin is recommended.

## Typeface sources

The repository may include references to example typefaces, but third-party fonts should only be redistributed when their respective licenses permit it. The application's code and third-party font licensing should be treated separately.

## Philosophy

Typography is not only selection.

It is behavior:

**hierarchy · rhythm · proximity · context · direction · reading**

The instrument exists to make those relationships observable.
