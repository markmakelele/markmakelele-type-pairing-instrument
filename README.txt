Type Pairing Instrument — bundled typeface edition

Open index.html in a modern browser. Keep the fonts and licenses folders beside
the HTML file so bundled typefaces can load. The instrument retains its existing
pairing, hierarchy, theme, specimen, search, upload, and font-library controls.

Bundled font families
- Nohemi: Thin through Black (weights 100–900), regular style.
- Blubird Text: Regular and Regular Italic.
- Blubird Display: Regular and Regular Italic.
- Strichpunkt Sans: variable weight and width font.

The font files are served locally by the page through @font-face. Their original
family and style distinctions are preserved in the CSS definitions.

Licenses
- Nohemi-EULA.pdf and Blubird-EULA.pdf are the supplied license terms for those
  font archives. Review them before redistributing or using the bundled files.
- Strichpunkt Sans is distributed under the Open Font License; see
  Strichpunkt-OFL.txt. The supplied readme is preserved as well.

Fira Code, Overpass Mono, and Xanh Mono remain in the existing selectors. The
source project did not include their referenced font files in its published
HTML, so browsers use the selectors' fallback stacks for those choices.
